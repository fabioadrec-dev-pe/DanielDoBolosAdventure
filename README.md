# DanielDoBolosAdventure
Jogo de plataforma 2D inspirado na era 16 bits (SNES), escrito em Java com LibGDX, renderizacao pixel-perfect (256×224 com escalonamento inteiro), fisica de plataforma classica, cinco fases com dificuldade crescente e chefe final. Empacota a JVM embarcada via jlink/jpackage para rodar sem o usuario instalar Java.
